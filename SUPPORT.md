# Support

## Where to Ask for Help

- **Bug reports**: open a GitHub issue with reproduction steps.
- **Feature requests**: open a GitHub issue describing the use case and expected outcome.
- **Security issues**: do **not** open a public issue; follow `SECURITY.md`.

## Before Opening an Issue

- Confirm the problem still reproduces on the latest `main` branch.
- Check the existing issues and pull requests first.
- Include the deployment mode, relevant versions, and sanitized logs if available.

## What Maintainers Can Help With

- Reproducible bugs in `apps/server`, `apps/frontend`, or `packages/shared`
- Documentation gaps or deployment guidance issues
- CI, workflow, or repository maintenance problems

## What Maintainers Cannot Help With

- Recovering leaked credentials that were already exposed publicly
- Debugging with unsanitized production secrets or raw user logs posted in public
- Private infrastructure access outside this repository
