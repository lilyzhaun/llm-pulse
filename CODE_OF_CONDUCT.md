# Code of Conduct

## Our Pledge

We want LLM Pulse to be an open, respectful, and constructive project for maintainers, contributors, and users. We expect everyone participating in this repository to treat others with professionalism and respect.

## Expected Behavior

- Be respectful in discussions, reviews, and issue reports.
- Focus feedback on the code, documentation, or proposal rather than the person.
- Use clear, reproducible technical reports when raising bugs or regressions.
- Protect private or sensitive information when discussing incidents.

## Unacceptable Behavior

- Harassment, personal attacks, or discriminatory language.
- Publishing private credentials, internal hostnames, raw logs, or exploit details in public threads.
- Spamming issues or pull requests without a clear technical purpose.

## Reporting

For conduct concerns, contact the repository maintainer through the same private channel used for security-sensitive operational issues. If the report also involves secrets or production data, follow the guidance in `SECURITY.md`.

## Scope

This Code of Conduct applies to repository discussions, issues, pull requests, code review, and other public project spaces.
